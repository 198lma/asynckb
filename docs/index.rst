asyncpg-kes
===========

**asyncpg-kes** extends asyncpg with KingbaseES MySQL, Oracle, and SQL Server
compatibility modes while retaining the ``asyncpg`` Python API and PostgreSQL
wire protocol implementation.

**asyncpg-kes** requires Python 3.9 or later.  The recorded acceptance suite
targets KingbaseES V009R001C010 MySQL, Oracle, and SQL Server compatibility
modes.  PostgreSQL is not part of this fork's acceptance matrix.
