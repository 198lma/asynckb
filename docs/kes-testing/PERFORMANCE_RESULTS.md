# asynckb 性能与短时压力测试结果

## 1. 测试结论

2026-11-19 15:33:39 至 15:42:42（北京时间），三模式共执行 21 组负载，
完成 1,901,403 次操作，执行错误 0。操作包括 1,845,492 次参数查询和
55,911 次事务；事务不是单条 SQL，二者不能当作同一吞吐口径比较。

查询值、事务行内容、提交/回滚后的最终行数均通过核对。池满获取连接产生预期超时，
释放连接后可继续查询。池连接全部归还，测试表已删除；独立复查三实例的本轮测试会话
和 `kb_perf_` 测试表，均无残留。预期的池获取超时不计为负载执行错误。

本轮未发现上述负载下的驱动执行或数据正确性问题，未修改驱动源码。
这是短时运行基线，不是生产容量验收；尚未完成 24 小时长稳或正式性能对比测试。

RSS 包含采样数组及 Python 分配器保留空间，不能仅凭本轮数据排除或确认内存泄漏。
执行开启 ResourceWarning/RuntimeWarning 严格检查，进程正常退出，未报告此类告警。

## 5. 限制与证据

尚未覆盖：24 小时长稳、大结果集/LOB/批量导入性能、远程网络及 TLS 成本、

不是“达到任意生产业务的性能要求”。
