# Security policy

## Supported version

Security fixes are applied to the latest `0.31.0.post*` release line.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting or open a private security
advisory for this repository. Do not disclose credentials, connection strings,
database contents, or an unpatched vulnerability in a public issue.

Include the affected version, KES compatibility mode, Python version,
platform, minimal reproduction, impact, and any proposed mitigation. Remove
all passwords and internal addresses from logs before attaching them.

Rotate any credential that has been pasted into chat, an issue, a log, or a
commit, even if it belongs only to a test environment.
